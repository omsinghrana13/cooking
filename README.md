# Final Burger Login Page

## Kaise Use Karein (How to Use in VS Code):

1. Is ZIP file ko **extract/unzip** karein.
2. Jo nayi photo aapne upload ki thi, usko download karein.
3. Us photo ka naam **`bg-image.jpg`** rakh dein (make sure it's a .jpg file).
4. Us `bg-image.jpg` ko extract kiye hue folder me (jahan index.html hai) daal dein.
5. VS Code me folder open karein.
6. `index.html` par right-click karke **"Open with Live Server"** par click karein.
